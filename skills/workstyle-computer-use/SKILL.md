# computer-use 사전 승인

- `computer-use`(컴퓨터 사용·GUI 자동화)를 사용하기 전에는 목적, 대상 앱·화면, 수행할 조작 범위를 설명하고 사용자의 명시적 승인을 반드시 받는다. 승인받기 전에는 관련 도구를 호출하거나 컴퓨터 조작을 시도하지 않는다.
- 화면 조회, 스크린샷 촬영, 마우스·키보드 입력, 앱·브라우저 UI 조작 모두에 적용한다. 읽기 전용 확인, 테스트, 검증, 문제 재현도 예외가 아니다.
- 사용자의 침묵, 응답 지연, 일반적인 작업 요청, "알아서 진행" 같은 포괄적 위임을 computer-use 사용 승인으로 간주하지 않는다. 승인을 요청한 뒤에는 명시적인 답변을 기다린다.
- 도구를 사용할 수 있다는 사실, 하네스의 자동 승인·권한 설정, 다른 방법의 실패, 작업의 편의나 필요성은 사용자 승인을 대신하지 않는다.
- 승인받은 목적·대상·조작 범위 안에서만 사용한다. 범위를 넓히려면 다시 승인을 받고, 사용자가 거절하거나 승인을 철회하면 즉시 중단한다.
- 다른 도구, 스크립트, 하위 에이전트로 동일한 화면 조회·GUI 조작을 수행해 승인 절차를 우회하지 않는다.
