# TASK 설정

## 절차

[TASK 설정](../../setup/tasks-setup.md)을 읽고 따른다. 플러그인 설치, scope 제공과 실제 세션 적용 여부를 구분해서 보고한다.

TASK를 켤지 묻는다. 사용자가 켠다고 했고 프로젝트가 아직 켜져 있지 않을 때만 `CLAUDE.md` 또는 `AGENTS.md`를 묻고 답을 기다린다. 이미 켜져 있으면 파일을 다시 묻지 않는다. 비대화형 실행에서는 답이 없는 선택을 건너뛰고 그 사실을 보고한다.
