# 작업 방식 플러그인 설치

## 선택

1. 현재 하네스와 이미 설치된 플러그인을 확인한다.
2. 사용자가 아직 지정하지 않았다면 스크립트 기반 TASK 추적과 미완료 작업 Stop 검사를 켤지 묻는다. 외부 플러그인 설치는 요청하거나 실행하지 않는다.
3. 이미 답한 항목은 다시 묻지 않는다. 응답 전에는 선택에 의존하는 변경을 하지 않는다. 비대화형 실행에서는 미선택 항목을 건너뛰고 보고한다.

## 설치

[플러그인 설치](../../setup/plugin-setup.md)를 따른다. TASK 선택은 [TASK 설정](../../setup/tasks-setup.md)에 적용한다.

하네스 훅은 `internal-workstyle` 스킬 호출을 안내하고, 스킬이 공통 규칙을 읽는다. `CLAUDE.md`나 `AGENTS.md`에 규칙을 복사하지 않는다. 특정 모델을 강제하지 않는다. 다른 도구의 설정, 권한, 인증과 기존 작업 기록을 보존한다.

## 확인

설치 목록, 스킬 발견, 훅 출력과 실제 세션 적용을 구분해 확인한다. 변경한 경로, 실제 검사 결과와 사용자가 해야 할 일을 보고한다.
