# 일반 교차 리뷰

## 실행

[내부 교차 리뷰 절차](../internal-cross-review/SKILL.md)를 읽고 일반 모드로 실행한다. 변경 범위의 정확성, 회귀, 요구사항 누락과 검증 공백을 확인한다.

사용자가 공격적 리뷰나 적대적 검토를 요청했으면 [adversarial-cross-review](../adversarial-cross-review/SKILL.md)를 사용한다.
