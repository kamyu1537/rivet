# 공격적 교차 리뷰

## 실행

[내부 교차 리뷰 절차](../internal-cross-review/SKILL.md)를 읽고 공격적 모드로 실행한다. 정확성과 회귀를 확인하고 설계 가정, 관련 호출 경로, 신뢰 경계와 실패·복구 경로에서 구체적인 반례를 찾는다.

검증한 가정과 반례, 검토하지 못한 경로를 결과에 적는다. 지적 개수를 채우거나 관련 없는 전면 감사로 범위를 넓히지 않는다.
