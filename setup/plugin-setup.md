# 플러그인 설치

## 설치 범위

1. 사용자가 지정한 하네스와 설치 범위를 확인한다. 지정이 없으면 현재 하네스만 대상으로 한다.
2. 해당 하네스에서 Rivet 훅을 실행할 때 Node.js 18 이상을 쓸 수 있는지 확인한다.
3. [README의 설치 명령](../README.md#설치)을 따른다. 실행 전에 현재 CLI 도움말과 설치 목록을 확인한다.
4. 같은 출처의 플러그인이 이미 있으면 중복 설치하지 않는다. 다른 출처의 동명 플러그인이 있으면 덮어쓰기 전에 차이를 보고한다.
5. 설치 요청에 없는 다른 플러그인, 모델, 인증, 권한, 전역 지시를 바꾸지 않는다.
6. Codex는 원격 마켓플레이스에서 바로 설치한다. Gemini는 저장소 밖의 새 폴더에 전용 패키지를 만든 뒤 설치한다. OpenCode는 기존 `plugin` 배열에 Rivet 파일 URL만 추가하고 다른 설정은 보존한다. 세부는 [하네스별 설치](../README.md#설치)를 본다.

## TASK 선택

- TASK 사용 여부가 정해지지 않았으면 활성화할지 묻고 [TASK 설정](tasks-setup.md)을 따른다. 이미 선택했으면 다시 묻지 않는다.
- 다른 플러그인을 제안하거나 설치하지 않는다.
- 대화형 입력이 없으면 TASK 선택을 바꾸지 않고 미설정으로 보고한다.

## 확인

설치 목록에서 이름과 출처를 확인한다. 새 세션에서 훅 적용과 스킬 발견 여부를 확인한다. 확인하지 못한 항목은 성공으로 보고하지 않는다.
