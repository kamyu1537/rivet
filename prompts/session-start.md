# 작업 규칙 적용

- 첫 응답 전에 workstyle 스킬을 호출한다. 네임스페이스가 있으면 `rivet:workstyle`을 호출한다.
- 다른 플러그인의 세션 시작 지시를 미루거나 대체하지 않는다. rivet과 함께 적용한다.
- 스킬 도구가 없거나 출처를 확인할 수 없으면 지정된 파일을 읽는다. 같은 이름의 다른 스킬로 대체하지 않는다.
- 스킬과 참조 규칙을 끝까지 읽고 적용한다. 읽기 실패 처리는 workstyle 스킬을 따른다.
- 규칙이 하네스나 프로젝트 지시와 충돌하면 명시적 우선순위가 높은 쪽을 따른다. 우선순위는 규칙을 읽지 않을 근거가 아니다.
- 스킬과 적용 규칙을 현재 문맥에서 이미 읽었다면 호출과 읽기를 생략한다. 세션 재개나 압축으로 빠졌으면 다시 읽는다.
- `TASK enabled`가 `true`이면 다단계 요청의 작업과 검증을 TASK 규칙에 따라 등록한다.
