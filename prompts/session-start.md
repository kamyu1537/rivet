# 작업 규칙 적용

- 현재 하네스와 프로젝트의 지시 우선순위를 따른다.
- 작업 전에 아래 `Workstyle skill` 경로의 `internal-workstyle` 스킬을 호출한다. 네임스페이스를 지원하면 `rivet:internal-workstyle`을 사용한다. 호출 도구가 없거나 스킬의 출처를 확인할 수 없으면 지정된 파일을 직접 읽는다. 같은 이름의 다른 스킬로 대체하지 않는다.
- 스킬과 참조 규칙을 끝까지 읽고 적용한다. 출력이 잘리면 나머지도 읽는다. 읽지 못하면 규칙을 적용할 수 없다고 사용자에게 알리고, 읽은 것처럼 계속하지 않는다.
- 스킬과 적용 규칙을 현재 문맥에서 이미 읽었다면 호출과 읽기를 생략한다. 세션 재개나 압축으로 빠졌으면 다시 읽는다.
- `TASK enabled`가 `true`이면 다단계 요청의 작업과 검증을 TASK 규칙에 따라 등록한다. 사용자나 프로젝트가 다른 추적 위치를 지정했다면 그 위치를 따른다.
